## 核心模块详解

### 1. DDL转换器 (DDLConverter)

**功能**：
- 解析源数据库的DDL语句
- 转换为目标数据库的语法格式
- 处理数据类型映射
- 优化目标数据库的特殊配置

**关键特性**：
- 支持多种数据库类型（MySQL、PostgreSQL、Oracle、SQL Server）
- 智能识别主键和约束
- 自动优化Doris UNIQUE模型
- 保留注释和默认值信息

### 2. DataX配置生成器 (DataXGenerator)

**功能**：
- 根据表结构生成DataX同步配置
- 支持多种源数据库的Reader插件
- 生成标准的DataX JSON配置格式
- 优化性能和错误处理参数

**配置结构**：
```json
{
  "job": {
    "setting": {
      "speed": {"channel": 3}
    },
    "content": [{
      "reader": {
        "name": "mysqlreader",
        "parameter": {
          "username": "...",
          "password": "...",
          "column": ["id", "name", ...],
          "connection": [{
            "table": ["table_name"],
            "jdbcUrl": ["jdbc:mysql://..."]
          }]
        }
      },
      "writer": {
        "name": "doriswriter",
        "parameter": {...}
      }
    }]
  }
}
```

### 3. SeaTunnel配置生成器 (SeaTunnelGenerator)

**功能**：
- 生成SeaTunnel的HOCON格式配置
- 支持流式和批处理模式
- 集成CDC（变更数据捕获）功能
- 配置数据转换和过滤规则

### 4. 类型映射系统

**映射规则**：
```python
# MySQL -> Doris 示例映射
TYPE_MAPPINGS = {
    "mysql": {
        "int": TypeMapping("INT", "INT", need_length=False),
        "bigint": TypeMapping("BIGINT", "BIGINT", need_length=False),
        "varchar": TypeMapping("VARCHAR", "VARCHAR", need_length=True),
        "datetime": TypeMapping("DATETIME", "DATETIME", need_length=False),
        "decimal": TypeMapping("DECIMAL", "DECIMAL", need_length=True, need_scale=True)
    }
}
```

## 数据流处理

### 转换流程
```
源DDL → 词法分析 → 语法解析 → 语义分析 → 类型映射 → 目标DDL
  ↓
表结构信息 → 配置生成 → DataX/SeaTunnel配置
```

### 错误处理流程
```
输入验证 → 解析处理 → 错误捕获 → 友好提示 → 日志记录
```

## 性能优化

### 1. 前端优化
- **组件懒加载**：按需加载页面组件
- **状态管理**：使用React Hooks优化状态更新
- **代码分割**：Vite自动进行代码分割
- **缓存策略**：API响应缓存和本地存储

### 2. 后端优化
- **异步处理**：使用FastAPI的异步特性
- **连接池**：数据库连接池管理
- **缓存机制**：热点数据缓存
- **日志优化**：结构化日志，便于排查问题

### 3. 算法优化
- **增量解析**：只重新解析变更的部分
- **智能缓存**：缓存常用的类型映射结果
- **并行处理**：支持批量转换的并行处理

## 扩展性设计

### 1. 新数据库支持
要添加新的数据库支持，需要：
1. 在 `TypeMapping` 中添加类型映射
2. 实现对应的DDL解析器
3. 添加Reader/Writer插件映射
4. 更新前端选择器

### 2. 新同步工具支持
要添加新的同步工具，需要：
1. 创建新的配置生成器类
2. 实现配置模板
3. 添加API端点
4. 更新前端界面

### 3. 自定义规则
支持通过配置文件自定义：
- 类型映射规则
- 转换优化规则
- 生成配置模板
- 错误处理规则

## 安全考虑

### 1. 输入验证
- DDL语句语法验证
- 参数类型和范围检查
- SQL注入防护
- 文件上传安全检查

### 2. 配置安全
- 敏感信息脱敏
- 配置文件权限控制
- 日志中不记录密码等敏感信息
- API访问频率限制

### 3. 部署安全
- 环境变量管理敏感配置
- Docker容器安全设置
- 网络安全策略
- 监控和告警机制
